# MIRROR

A social network built around perspective instead of popularity.

## Concept

MIRROR lets people step into real situations, make decisions before seeing someone else's choice, and then reflect on how context changes perspective.

Core loop:

Situation → Decide → Reveal → Context → Perspective Shift → Reflect

## Features

- Blind decision-making
- Multi-option situations
- Perspective reveal
- Context and reasoning
- Perspective Shift
- Reflection responses
- Echoes / perspective notes
- Explore perspectives
- Create your own Mirror
- Responsive editorial interface
- Frontend-only localStorage persistence

## Tech Stack

- Vite
- Tailwind CSS / CSS
